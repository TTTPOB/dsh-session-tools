# ADR 0005：移除模型上下文地图接口

- 状态：Accepted（已采纳）
- 取代：[ADR 0004：通用 Surface 地图与同源计量](<0004-context-map-and-metering.md>)的模型地图与 map-specific 公共接口设计。

## 背景

ADR 0004 以独立地图服务模型浏览和 ACP 选区，共享节点采样、定位、预览与计量展示。[ACP ADR 0003](<../../../dsh-active-context/docs/adr/0003-text-anchored-compaction.md>)改为由工作模型直接提交当前 Surface 的原文端点，不再依赖地图取得范围引用。保留地图仍有独立浏览价值，但需要继续维护工具、输出预算、预览、定位协议及公共库消费者。

session-tools 的核心职责是索引化历史检索和精确回读。当前选择不再为 ACP 之外维护另一套模型 Surface 导航接口；文本选区属于压缩提交时的目标解析，与普通历史搜索不同。

## 决策

移除本包模型工具 `session_context_map` 及 map-specific 公共库/API，包括 `context-map` 库入口、地图 DTO、定位、预览与展示预算接口。专用接口与其消费者的依赖同步移除，ACP 的提交输入和提醒协议由 ACP ADR 0003 定义，本 ADR 不复制其 literal 匹配细则。

保留以下职责和底层能力：

- 现有 session/event 的 list、read、search、trace，以及既定作用域、分页、关联与完整回读协议。
- 搜索仍仅消费 Query 的索引 FTS 查询；索引禁用、不支持或失败时保留原错误，不扫描日志兜底，也不提供 Surface 文本搜索 fallback。
- Query `captureSession` 同步采样和 tokenMeter 及其计量依据仍可独立复用，不因地图接口移除而撤销。底层采样与计量能力不等于必须提供模型地图。

本包不接管压缩端点的文本定位，不新增 lookup/ref/ID 选择接口。ACP 通过 Query 对当前调用会话采样、解析并验证完整压缩目标；普通历史搜索与回读继续遵循本包既有契约。

## 理由与替代方案

- **保留地图为独立浏览器。** 对结构、体量和无 text 节点的浏览仍有价值；但在 ACP 不再消费地图后，维持其独立接口、预算和导航协议不符合当前职责选择。移除不是认定地图没有用途。
- **保留紧凑地图。** 删除冗余 DTO 字段或只提供短 range 表可以减少输出，却仍保留前置取图调用、结果预算与消费者维护。当前选择取消该导航接口，而非继续维护另一种地图表示。
- **把文本定位放进 session-tools。** 可以集中数据访问，但会将本包的索引搜索和回读扩展为 Surface 字面选择服务，并使压缩目标解析跨消费者分散。定位留在 ACP 的同步提交与保护预检中，不改变本包 FTS 的含义，也不以文本扫描补偿索引失败。
- **连同地图移除 Query 采样或计量。** 这些是独立底层能力，ACP 仍需要一致采样与计量；取消展示层不构成移除它们的理由。

## 后果

session-tools 不再承担模型上下文地图、地图专用公开库和相应输出预算的维护，ACP 不再以取图为提交前置条件。模型侧失去独立的 Surface 结构和逐段体量浏览接口；普通历史工具仍可读取与追溯原事件，但不冒充当前 Surface 地图或当前节点存活保证。
